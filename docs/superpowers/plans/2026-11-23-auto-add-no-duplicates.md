# Auto-add without duplicates Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auto-add never appends a repo path that `dock.git.repos` already lists. A repo whose listing keeps
failing then can't grow the list by one entry per second.

**Architecture:** In `applySkipAndAutoAdd`, the collector drops any candidate whose id (`idOf(machine, path)`) is
already the id of an entry in this tick's `addedList`. This is the same check the panel's "+ Add repo" makes
(`addRepoPath` in `src/mods/dock-git/view.js`). Nothing else changes.

**Tech Stack:** plain ES modules in `src/shared` (bundled into Herdr mods), `node --test`, esbuild via
`npm run build:app`.

**Spec:** `docs/superpowers/specs/2026-11-22-auto-add-repos-design.md`, Design / Auto-add: "nothing is appended
twice". The spec's guard covers only entries still being resolved. This plan covers resolved entries whose
listing failed.

## Root cause (reproduced 2026-11-23)

- **Two ids for one repo.** An added entry whose `worktree list` fails has no common dir, so `buildView` keys its
  row by the entry's path (`|/w/api`). A terminal in that repo is keyed by its common dir (`|/w/api/.git`). The
  ids never match, so the terminal's row counts as "not added".
- **No check against the list.** `applySkipAndAutoAdd` (`src/shared/collector.js:369-374`) appends that row's
  path without checking `dock.git.repos`.
- **Growth.** Next tick the duplicate entry maps to the same failing entry, so the same two rows appear and the
  path is appended again: one entry per tick. A scratch repro went from 1 entry to 12 in 11 ticks.
- **When it happens:** the listing fails while a terminal is in the repo. Examples: a remote machine that became
  unreachable after its terminal's folder was resolved, or a listing given up after 30 s (`ed3419f`).

## Global Constraints

- `src/shared/*.js`: no Node built-ins and no `setTimeout`. Time comes only from `io.now()`.
- Ids come from `idOf(machine, path)`, which is `worktreeId` with this computer's platform for local entries.
  It folds case on Windows and strips trailing slashes, so never compare raw strings.
- Out of scope, per Adam's scope rule:
  - the duplicate error row shown while a listing fails (a deferred minor from the last review);
  - cleaning up duplicates already in a grown `dock.git.repos`.
- `app/` is a committed build. Run `npm run build:app` and commit `app/` in the same commit.
- Work on a branch from `main`, and merge back to `main` (project memory: fix-branches-base-on-main).
- Commit messages follow the repo's `fix(collector): …` style and end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Baseline** (`main` = `ed3419f`):
  - Node 23.11 (`/opt/homebrew/bin/node --test`): 616 of 616 pass.
  - Node 22.14 (`npm test`): 614 tests, 613 pass. The only failure is `tests/dock-core-class.test.mjs`, which
    needs Node ≥ 22.15.

## Review Focus

1. **A repo nobody added yet** is still auto-added exactly once. Covered by the existing test "auto-add: a repo a
   terminal works in is added (with its machine) and stays after the terminal closes".
2. **On Windows, a path added in a different case** (`D:/Work/Api` vs git's `D:/work/api`) counts as already
   listed. Test (b).
3. **The same path on another machine** is a different repo and is still added. Test (c).
4. **A listing that keeps failing** leaves `dock.git.repos` at exactly its original entries. Test (a).
5. **A path hand-added with a trailing slash** (`/w/api/`) counts as already listed. `idOf` strips the slash, and
   `worktreeId` is tested in `tests/git.test.mjs`, so there's no new test.

```js
// --- auto-add never appends a path already listed (docs/superpowers/plans/2026-11-23-auto-add-no-duplicates.md) ---
const refused = () => { throw new Error("ssh: connection refused"); };
const ticks = async (io, c, n) => { for (let i = 0; i < n; i++) { io.t = i * 1000; await c.tick(); } };

test("auto-add (a): a repo whose listing keeps failing isn't appended again every tick", async () => {
  const io = fakeIo({
    platform: "linux", autoAdd: true, spaces: oneSpace, repos: [{ path: "/w/api", machine: null }],
    panes: [{ pane: "p1", tab: "t1", cwd: "/w/api" }],
    table: {
      [` -C /w/api ${RP}`]: ok("/w/api\n/w/api/.git\n"),
      " -C /w/api worktree list --porcelain": refused,
      " -C /w/api remote get-url origin": NO_ORIGIN,
      " --no-optional-locks -C /w/api status --porcelain=v2 --branch": status("main"),
    },
  });
  const c = createCollector(io);
  await ticks(io, c, 11);
  assert.deepEqual(io.shared("dock.git.repos"), [{ path: "/w/api", machine: null }]);
});

test("auto-add (b): on Windows, an added path in another case counts as listed", async () => {
  const io = fakeIo({
    platform: "windows", autoAdd: true, spaces: oneSpace, repos: [{ path: "D:/Work/Api", machine: null }],
    panes: [{ pane: "p1", tab: "t1", cwd: "D:/work/api" }],
    table: {
      [` -C D:/Work/Api ${RP}`]: ok("D:/work/api\nD:/work/api/.git\n"),
      [` -C D:/work/api ${RP}`]: ok("D:/work/api\nD:/work/api/.git\n"),
      " -C D:/work/api worktree list --porcelain": refused,
      " -C D:/work/api remote get-url origin": NO_ORIGIN,
      " --no-optional-locks -C D:/work/api status --porcelain=v2 --branch": status("main"),
    },
  });
  const c = createCollector(io);
  await ticks(io, c, 5);
  assert.deepEqual(io.shared("dock.git.repos"), [{ path: "D:/Work/Api", machine: null }]);
});

test("auto-add (c): the same path on another machine is a different repo, still added once", async () => {
  const io = fakeIo({
    platform: "linux", autoAdd: true, repos: [{ path: "/w/api", machine: null }],
    spaces: [{ id: "s1", name: "a", machine: "devbox", tabs: [{ id: "t1" }] }],
    panes: [{ pane: "p1", tab: "t1", cwd: "/w/api" }],
    table: {
      [` -C /w/api ${RP}`]: ok("/w/api\n/w/api/.git\n"),
      " -C /w/api worktree list --porcelain": refused,
      [`devbox -C /w/api ${RP}`]: ok("/w/api\n/w/api/.git\n"),
      "devbox -C /w/api worktree list --porcelain": refused,
      "devbox -C /w/api remote get-url origin": NO_ORIGIN,
      "devbox --no-optional-locks -C /w/api status --porcelain=v2 --branch": status("main"),
    },
  });
  const c = createCollector(io);
  await ticks(io, c, 5);
  assert.deepEqual(io.shared("dock.git.repos"), [{ path: "/w/api", machine: null }, { path: "/w/api", machine: "devbox" }]);
});
```
